Uso de inteligencia artificial

Durante el desarrollo de Bloomy — Make your days bloom, se utilizaron distintas herramientas de inteligencia artificial como asistentes de desarrollo, con el objetivo de facilitar la resolución de problemas técnicos, mejorar la organización del código y acompañar el proceso de implementación.

Las herramientas utilizadas fueron ChatGPT, Claude Code y Antigravity.

1. ChatGPT

Se utilizó principalmente como asistente técnico y herramienta de aprendizaje durante el desarrollo.

Sus intervenciones incluyeron:

* Planificación de la arquitectura y organización de funcionalidades.
* Explicación de conceptos de React, TypeScript y Firebase.
* Asistencia en la implementación de autenticación y operaciones CRUD.
* Diseño de la lógica de gamificación y progresión del jardín.
* Revisión de código y resolución de errores.
* Diseño de estrategias de testing.
* Revisión de reglas de seguridad de Firestore.
* Resolución de problemas de configuración y despliegue de Vercel y AWS SES.
* Asistencia en la elaboración de documentación técnica.

Ejemplo representativo de interacción (reconstruido):

Problema: evitar que una tarea completada otorgue puntos de recompensa más de una vez.

Asistencia: análisis de alternativas para implementar transacciones de Firestore que permitan actualizar el estado de una tarea y acreditar sus puntos de manera atómica.

Resultado: implementación de un sistema de recompensas persistente y validación mediante pruebas.

2. Claude Code

Se utilizó como herramienta de asistencia durante el desarrollo y trabajo con el código fuente.

Su participación formó parte del proceso de implementación y evolución del proyecto.

No se conservaron transcripciones completas de las sesiones, por lo que no se presentan conversaciones literales ni prompts atribuidos a esta herramienta.

3. Antigravity

Se utilizó como entorno de asistencia para trabajar sobre la estructura y presentación del proyecto.

Entre las tareas realizadas se encontraron:

* Creación y reorganización de carpetas y archivos.
* Reorganización de código existente.
* Modificaciones específicas de estilos CSS.
* Ajustes de componentes y presentación visual.
* Cambios puntuales en archivos del proyecto.

Las intervenciones se realizaron sobre el código existente y fueron revisadas durante el proceso de desarrollo.

4. Participación y validación

Las herramientas de inteligencia artificial se utilizaron como apoyo, no como sustituto del proceso de desarrollo.

Las decisiones de implementación, integración y aceptación de cambios fueron supervisadas por la desarrolladora.

Las funcionalidades fueron verificadas mediante pruebas, revisión del comportamiento de la aplicación y validación en el entorno de producción.

La integración de las herramientas no reemplazó la necesidad de comprender, revisar y comprobar el código generado o modificado.
